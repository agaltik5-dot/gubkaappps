# Адаптация темы для карточек расписания

Мы исправили проблему с отображением аудиторий в темной теме, сделав интерфейс полностью адаптивным и читаемым в любых условиях.

## Что было сделано

### [Исправление темной темы]
*   **Динамический фон аудиторий**: Мы убрали жестко заданный светлый цвет для плашек кабинетов. Теперь фон плашки автоматически подстраивается под выбранную тему:
    *   **В светлой теме**: Остается светло-серым для мягкого контраста.
    *   **В тёмной теме**: Становится темно-серым, обеспечивая отличную читаемость белого текста и иконок.
*   **Семантические цвета**: Создан новый ресурс цвета `ui_chip_bg`, который позволяет централизованно управлять фоном всех подобных элементов в приложении.

## Результат
*   **Читаемость**: Номера аудиторий теперь четко видны как днем, так и ночью.
*   **Комфорт**: Интерфейс больше не "слепит" яркими пятнами при использовании темной темы.
