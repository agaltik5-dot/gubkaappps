# Walkthrough - Исправление WebView и Умная Синхронизация (V2)

Я внес дополнительные улучшения, чтобы процесс загрузки был прозрачным и надежным. Теперь вы всегда будете знать, что происходит в фоновом режиме.

## Что нового

### 1. Уведомления в статус-баре
Добавлена поддержка системных уведомлений. Когда приложение начинает синхронизацию:
- В шторке уведомлений появляется запись: **"Синхронизация расписания... Загрузка данных..."**.
- По завершении уведомление обновляется: **"Синхронизация завершена. Загружено X недель"**.
Это позволяет видеть прогресс, даже если вы переключились на другое приложение.

### 2. Принудительное обновление данных
Чтобы расписание не оставалось "старым":
- При каждом срабатывании синхронизации приложение **удаляет старый кэш** для всех групп.
- К запросам API добавлен заголовок `Cache-Control: no-cache`.
- В объединенном расписании теперь отображается точное **время последнего обновления** в верхнем углу.

### 3. Исправление "Тихой" ошибки
Добавлена проверка сессии перед началом загрузки. Если капча пройдена, но куки не подхватились, приложение выдаст четкое сообщение: **"Сессия не найдена. Обновите страницу"**, вместо того чтобы просто ничего не делать.

### 4. Улучшенная навигация в WebView
На страницу с расписанием добавлена кнопка **"В браузер"**. Она позволяет мгновенно вернуться к обычному поиску, если вам нужно сменить параметры или зайти под другим пользователем.

## Как проверить

1. Откройте вторую вкладку.
2. Пройдите капчу (выберите любую группу).
3. Обратите внимание на шторку уведомлений — там должен появиться значок синхронизации.
4. Дождитесь появления объединенного расписания. Проверьте время обновления вверху страницы.

> [!IMPORTANT]
> Если расписание все равно кажется старым, нажмите кнопку **"Обновить"** на самой странице расписания или потяните страницу вниз (Swipe-to-refresh) — теперь это принудительно сбросит кэш и запросит новые данные.
