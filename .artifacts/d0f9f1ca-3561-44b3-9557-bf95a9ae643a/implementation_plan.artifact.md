# План реализации — Исправление WebView и Умная Синхронизация Расписания

Цель: исправить баг прокрутки в WebView и реализовать автоматическую загрузку расширенного расписания (основная группа + 5 последних) после того, как пользователь пройдет капчу на сайте во второй вкладке.

## Уточненная логика работы
1. Пользователь открывает вторую вкладку ("Поиск").
2. Пользуется сайтом как обычно, пока не пройдет капчу/авторизацию.
3. Как только сессия становится активной, приложение "подхватывает" куки и загружает в этот же WebView единую страницу с расписанием:
    - Текущей выбранной группы (из настроек).
    - 5 последних групп из истории.
    - Период: 2 недели для каждой группы.
4. Исправляется баг, при котором `SwipeRefreshLayout` мешает скроллить страницу вверх.
